# Blog article pictures

Each blog article has one big picture at the top. To change it, drop an image
in this folder named after the article's web address.

For example, the article at

    bhramanyatri.com/blog/what-to-pack-for-a-himalayan-trek

uses a file named

    what-to-pack-for-a-himalayan-trek.jpg

That last part of the web address is the filename. Copy it exactly, add
`.jpg` (or `.png`, `.webp`, `.avif`) and the website picks it up on its own.

If there is no matching file here, the article keeps the picture it was set up
with — nothing breaks.

## After adding pictures

The website needs to be published again (your developer or hosting provider
calls this "deploy") for the new pictures to appear online.
