# Drop your photos here

Any image you put in this folder appears on the website's Gallery page.

- **As many as you like.** There is no limit.
- **Any filename.** No naming rules to follow.
- **Folders are fine.** Make sub-folders like `kedarkantha-2025/` or
  `winter-batch/` to stay organised — photos inside them still show up.
- **Accepted types:** `.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`

## Tip: name files descriptively

The website turns the filename into the image's description for screen readers
and Google. So a file named:

    kedarkantha-summit-sunrise.jpg

is described as "Kedarkantha summit sunrise". A file named `IMG_4821.jpg` still
works, it just gets a generic description. Descriptive names are better for
search results, but never required.

## After adding photos

The website needs to be published again (your developer or hosting provider
calls this "deploy") for new photos to appear online.
