# Photos for the Chopta Tungnath with Chandrashilla Trek

Drop your photographs of this trek into **this folder**.

- As many as you like. There is no limit.
- Any file name. `.jpg`, `.jpeg`, `.png`, `.webp` and `.avif` all work.
- They appear in the Gallery section on the Chopta Tungnath with Chandrashilla Trek page, and on the
  website's main Gallery page.

Naming a file descriptively (for example `sunrise-from-the-summit.jpg`) gives
it a better description for Google and for screen readers, but it is never
required.

After adding photos the website needs to be published again (deploy) for
them to appear online.
