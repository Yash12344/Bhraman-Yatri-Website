# Per-trek photo galleries

To add photos to a single trek's page, create a folder here named exactly after
that trek, and put the photos inside.

    kedarkantha-trek/
    hampta-pass-trek/
    valley-of-flowers-trek/

The folder name must match the trek's file in `data/treks/` — for example
`data/treks/kedarkantha-trek.json` pairs with a folder called
`kedarkantha-trek`.

Photos placed here appear in two places: the Gallery section on that trek's own
page, and the site-wide Gallery page.

As many images as you like, any filenames. See the guide in
`public/site-images/gallery/README.md` for naming tips.
